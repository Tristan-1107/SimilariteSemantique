Cette version du site est en HTML/CSS pur. Quand l'URL du site est ouverte, GitHub Pages charge automatiquement ce fichier index.html.

Ce que tu voulais

  • Pas de port local a ouvrir sur ton PC
  • Un vrai fichier index.html comme point d'entree
  • Un style separe dans styles.css
  • Un deploiement automatique vers une URL en .github.io

URL cible

Si le depot reste Tristan-1107/SimilariteSemantique, l'URL GitHub Pages attendue sera :

https://tristan-1107.github.io/SimilariteSemantique/

L'ouverture de cette URL affichera directement le contenu de index.html du dossier site/ une fois le workflow GitHub Pages active et execute.

Contenu du projet

Le depot contient toujours ton application FastAPI pour le calcul de similarite, mais cette page sert une version statique adaptee a GitHub Pages.

Frontend statique

Les fichiers de cette vitrine sont dans le dossier site/. Ils peuvent etre heberges tels quels.

Backend Python

Le code FastAPI reste dans app/. Il continue d'etre utile pour un hebergement serveur classique.

Deploiement automatique

Un workflow GitHub Actions publie uniquement la version statique vers GitHub Pages a chaque push sur une branche configuree.

Limitation importante

GitHub Pages n'execute pas Python, FastAPI, ni les plugins de calcul. Cela veut dire que le site en .github.io peut afficher une interface statique, mais pas faire tourner directement les calculs semantiques du backend.

Si tu veux plus tard des calculs en ligne, il faudra soit :

  • heberger l'API FastAPI sur un service serveur, puis relier ce site a cette API
  • ou transformer une partie du projet en JavaScript pur cote navigateur
